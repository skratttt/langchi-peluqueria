Crea la primera versión de un chatbot de consola en Python 3 para Peluquería Barrio Sur, un negocio ficticio de Chile. Usa un modelo local Qwen2.5 7B Instruct mediante Ollama. Debe identificar qué necesita el cliente, contestar con la ficha y reunir servicio, día y hora para resumir una solicitud. Una solicitud no está reservada y el bot no tiene información de disponibilidad. Si alguien corrige un dato, conserva los datos restantes. Maneja expresiones chilenas y pide precisión cuando falten datos o haya ambigüedad.

Ficha completa: corte $12.000 CLP, barba $8.000 CLP y color $30.000 CLP. Abierto de lunes a viernes de 10:00 a 19:00 y el sábado de 10:00 a 16:00. Cerrado el domingo. Dirección ficticia: Avenida Los Telares 184, Ñuñoa, Santiago. Solo ofrece los tres servicios indicados.

Para poder evaluar y simplificar el resultado, usa estas cinco etiquetas de intención: precio, horario, ubicacion, solicitud y otra. Expón una clase Chatbot con constructor Chatbot(consultar=None), un método detectar_intencion(self, mensaje) y otro responder(self, mensaje). El último debe devolver un diccionario con intencion, datos y respuesta. En datos usa solo las claves servicio, dia y hora y deja los campos faltantes con null/None; escribe el día en español, el servicio tal como aparece en la ficha y la hora en formato HH:MM cuando sea inequívoca. Usa un historial por instancia. La función de detección de intención debe estar separada para poder reemplazarla por reglas. Para cada consulta al modelo llama a consultar(mensajes, json_mode=True), una función que recibe mensajes estilo chat de Ollama y devuelve texto; ofrece un valor por defecto que haga la solicitud HTTP local con urllib, usando temperatura 0. Incluye un punto de entrada de consola que imprime solo el campo respuesta. Usa únicamente la biblioteca estándar en un solo archivo y entrega un bloque Python, seguido de una explicación breve de cómo ejecutarlo.
